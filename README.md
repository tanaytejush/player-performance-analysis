# Player Performance Analysis

This is a public overview of work I did with the ScoutEdge team on analysing cricket player performance from video.

The main focus was player movement and action analysis. We worked with pose information from video, extracted useful features, and used machine-learning models to classify actions. The results were then connected to backend services so they could be used by an application rather than staying in a notebook.

## What I worked with

- Python
- OpenCV
- MediaPipe
- scikit-learn
- FastAPI
- REST APIs
- Docker

## My contribution

I contributed to the computer-vision and AI/ML workflows, including player movement and action analysis. I also worked on FastAPI inference services, deployment-related tasks, debugging, and getting the different parts of the workflow to work together.

This was a team project. The work involved several parts of a larger system, so this repository does not claim to represent a solo implementation.

## About this repository

The original work was developed for ScoutEdge. This repository is a public summary rather than a copy of the internal codebase.

It does not contain:

- Internal scoring formulas or rating logic
- Private datasets, player data, or videos
- Company-specific services or deployment configuration
- Trained model files or internal documentation
