# Player Performance Analysis

An AI/ML and computer vision project for analysing cricket player movement and actions from video.

This repository is a public-safe overview of work completed as part of the ScoutEdge team. It focuses on the problem, engineering approach, and technology choices without exposing proprietary scoring formulas, private datasets, internal services, or company-specific implementation details.

## What the project explores

- Extracting pose and movement information from cricket video
- Classifying player actions from visual input
- Building API-oriented workflows around ML inference
- Structuring results so they can support player performance analysis
- Designing deployment and debugging workflows for computer-vision services

## Technical focus

- **Programming:** Python
- **Computer vision:** OpenCV, MediaPipe
- **Machine learning:** scikit-learn
- **Backend:** FastAPI, REST APIs
- **Deployment:** Docker and production-oriented service workflows

## Engineering approach

The work connected video processing, pose-based feature extraction, model inference, and backend APIs. The emphasis was on making computer-vision output usable by an application rather than keeping the work inside an isolated notebook.

The project was developed collaboratively as part of the ScoutEdge team. My contributions included work across AI/ML and computer-vision workflows, player movement and action analysis, FastAPI inference services, deployment, and debugging.

## Scope and privacy

This public repository intentionally does not include:

- Proprietary rating formulas or internal scoring logic
- Private player data, datasets, or video
- Internal architecture, service implementations, or deployment configuration
- Trained model artifacts or company-internal documentation
